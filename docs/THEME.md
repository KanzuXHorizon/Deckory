# Deckory Editorial Theme

| Token | Value | Meaning |
| --- | --- | --- |
| Ink | `#15171A` | primary type and navigation |
| Canvas | `#F7F7F4` | warm workspace neutral |
| Cobalt | `#4F46E5` | emphasis and active progress |
| Teal | `#0F8B8D` | system quality and ready status |
| Amber | `#C77700` | attention, never a primary UI colour |
| Border | `#D8DAD6` | quiet structural separation |

Use Be Vietnam Pro or a legible sans fallback for Vietnamese body/display text. Use Geist Mono only for metadata, IDs and labels. Motion is directional (8–12px) and short (under 350ms); respect `prefers-reduced-motion`.
