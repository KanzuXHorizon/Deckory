# Deckory Components

| Component | Use it for | Required props |
| --- | --- | --- |
| `heading` | insight-led slide title | `title` |
| `statement` | a memorable argument | `quote` |
| `metric-grid` | three related signals | `metrics` |
| `chart` | a labelled comparison or trend | `title`, `unit`, `values` |
| `comparison` | before/after or two alternatives | `left`, `right` |
| `process` | a finite workflow | `steps` |
| `architecture` | systems layers and relationships | `layers` |
| `evidence-footer` | source / page provenance | `source` |

Every component must retain a static interpretation in reduced-motion and future export modes.
