# Security Policy

## Supported versions

Deckory is currently developed from the `main` branch. Security fixes target the latest revision unless a maintained release line is announced.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting feature for this repository. Include:

- the affected revision or commit;
- reproduction steps or a minimal proof of concept;
- expected and observed impact;
- any suggested mitigation;
- whether sensitive data or credentials may have been exposed.

Avoid including real credentials, private deck content or personal information. Reports will be assessed based on reproducibility, impact and the currently documented product boundary.

## Scope notes

Deckory currently uses local draft persistence and does not claim production-grade accounts, cloud persistence or real-time collaboration. Security reports should distinguish implemented behavior from features that are explicitly outside the current scope.
