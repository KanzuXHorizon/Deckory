# Support

Deckory is under active development. Before opening an issue:

1. Read the README and repository conventions in `AGENTS.md`.
2. Use the latest `main` branch and Node.js 24 or newer.
3. Run `pnpm install --frozen-lockfile`.
4. Reproduce the issue with `pnpm dev` or the smallest relevant test.
5. Check existing issues for duplicates.

Use the bug report template for reproducible defects and the feature request template for product proposals. Include expected behavior, actual behavior, reproduction steps, environment details and minimal evidence.

Do not publish credentials, private deck content, personal data, access tokens or sensitive logs. Report vulnerabilities privately through GitHub Security Advisories as described in `SECURITY.md`.

General setup questions may be opened as issues when the documentation does not answer them and the question is likely to help other users.
